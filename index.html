1. 可視化とは

可視化（visualization）とは、文字どおり目に見えるようにすること。データをそのまま眺めただけでは分からない性質を、図にすることで捉えやすくする。

データを手に入れたら、いきなり回帰分析などを始めるのではなく、まず図にしてみる。どんな人が何人いるのか、値はどのくらいばらついているのか、外れた値はないか、2つの変数にどんな関係がありそうか。これを先に見ておくと、その後の分析を効果的・効率的に進められるし、分析の結果が図と食い違ったときに誤りに気づける。

見たいもの使う図今日の例
カテゴリごとの人数・平均棒グラフ部署別の人数、部署別の平均時給
1つの数値の分布ヒストグラム・密度プロット時給の分布
2つの数値の関係散布図年齢と時給、生産性と時給
グループ間での分布の違い箱ひげ図勤務形態別・男女別の時給
2つのカテゴリの組み合わせごとの値ヒートマップ部署×勤務形態の平均時給

4. 1変数の可視化：棒グラフとヒストグラム

棒グラフ：カテゴリごとの人数

棒グラフが扱うのはカテゴリデータ（部署、性別、学歴、勤務形態のように、グループに分けたデータ）。棒の長さは、そのカテゴリの件数（人数）や平均・合計を表す。棒と棒の間には隙間があり、それぞれ別のグループであることを示す。

ggplot2 の図は「データ」＋「どの変数をどこに対応させるか（aes()）」＋「どんな図形で描くか（geom_〇〇()）」を + でつないで作る。aes は aesthetic（見た目）の略で、データの値を、横軸・縦軸・色・形といった見た目に翻訳する役割を持つ。

ラベルが重なるとき部署名が長いと横軸のラベルが重なるので、最後の theme() の行で45度傾けている。この行を消して aes(x = dept) を aes(y = dept) に変えると、棒が横向きになって部署名が読みやすくなる（そのときは labs() の x と y も入れ替える）。試してみよう。

fill = を aes() の中に書くと、変数の値によって棒を塗り分けられる。勤務形態で塗り分けてみよう。

図から読み取ろうハイブリッド勤務の社員はどの部署にいるか。ハイブリッド勤務を認めている4部署でも、完全出社を選んでいる人がいることを確かめよう。

並び順を指定する

文字のデータは、そのままだと文字コードの順に並ぶ。学歴なら教育年数の短い順に並べたい。factor() で順番（levels）を指定する。

|>（パイプ）とはA |> B は「Aを、次のBに渡す」という意味。misaki |> mutate(…) は「misakiのデータに、mutate（列を作る・作り直す）を行う」と読む。手順を上から順に書けるので読みやすい。
  • |> はR 4.1以降に標準で入っているパイプで、パッケージなしで使える。RStudioでは Ctrl＋Shift＋M（Macは ⌘＋Shift＋M）で入力できる。|> が入るようにするには、Tools → Global Options → Code で「Use native pipe operator, |>」にチェックを入れる
  • Webの解説記事や生成AIの答えでは、同じ働きをする %>%（tidyverseに入っている古くからのパイプ）をよく見かける。今日のコードの範囲では、どちらを使っても結果は同じ

棒グラフ：カテゴリごとの平均

棒の長さで平均を表すこともできる。先に group_by() と summarise() で部署ごとの平均時給を計算し、その値をそのまま棒の長さにする（geom_col()）。

ヒストグラム：時給の分布

ヒストグラムが扱うのは連続量（時給・年齢・生産性のように、数値が連続して変わるデータ）。数値を区間（bin）に分け、それぞれの区間に何人が入ったか（度数）を棒の高さで表す。棒と棒の間に隙間がないのは、区間がつながっていることを示す。分布の形（左右対称か、右に裾が長いか、山が2つあるか）が分かる。

やってみようbinwidth = 250 を 100 や 500 に変えて実行してみよう。区間の分け方を細かくするか粗くするかで、分布の見え方はどう変わるだろうか。

年齢は整数なので、棒グラフ（geom_bar()）で1歳ごとの人数を数えることもできる。ヒストグラムと見比べてみよう。

6. グループを比べる：箱ひげ図

グループごとの分布を比べるには箱ひげ図が便利。箱の中の線が中央値、箱の下端と上端が第1四分位と第3四分位（真ん中の半分の人がこの範囲に入る）、ひげは箱から離れすぎていない範囲の最小・最大を表す。ひげの外にある点は外れ値の候補。

geom_jitter() を重ねると、1人ひとりの点を少しずつ左右にずらして表示できる。箱だけでは分からない人数や散らばりも見えるようになる。

やってみよう上のコードの sex（2か所）を workstyle に変えて、勤務形態ごとの時給を比べてみよう。labs() の文字も直しておく。

7. 応用：分割・重ね合わせ・ヒートマップ

グループごとに図を分割する：facet_wrap()

部署ごとの時給のヒストグラムを、部署別に並べて描く。facet_wrap(~ 変数) を足すと、その変数の値ごとに図を分割できる。

2つのカテゴリで同時に分けて比べる

時給を、勤務形態と性別という2つのカテゴリで同時に分けて比べる。横軸を勤務形態にし、fill = sex で男女の箱を並べる。箱ひげ図の応用である。

注意しようハイブリッド勤務者には女性が多い（40人中20人。完全出社は80人中24人）。勤務形態だけで比べた差には、性別の違いによる部分が混ざっているかもしれない。男女それぞれの中で勤務形態を比べると、差はどう見えるだろうか。

分布を重ねて比べる：密度プロット

ヒストグラムは区間の幅によって形が変わる。分布を滑らかな曲線（密度）で表す密度プロットは、複数のグループの分布を重ねて比べるのに向いている。alpha で半透明にすると、重なった部分も見える。縦軸の「密度」は、曲線の下の面積が1になるように描いた高さで、人数の多いグループと少ないグループの分布の形を同じ土俵で比べられる（ハイブリッド40人、完全出社80人）。

ヒストグラムを重ねることもできる（position = "identity" で棒を重ねる）。

生成AIに聞いてみよう重なっていると見にくいかもしれない。上下や左右に並べるにはどう書けばよいだろうか。生成AI（Geminiなど）に、上のコードを貼り付けて「勤務形態ごとに上下に分けて表示したい」と聞いてみよう。何をしたいかがはっきりしていれば、生成AIの支援はとても役に立つ。
答えの例

+ facet_wrap(~ workstyle, ncol = 1) を足すと上下に分かれる。棒を横に並べるなら position = "identity" を position = "dodge" に変える。

2つのカテゴリの組み合わせ：ヒートマップ

2つのカテゴリ変数を縦と横に並べたマス目（タイル）を作り、マス目ごとの値（平均・人数など）を色の濃さで表すのがヒートマップ。部署と勤務形態の組み合わせごとに平均時給を計算して描く。

図から読み取ろう空白のマス目があるのはなぜだろうか（「2. 今日のデータ」の設定を思い出そう）。勤務形態による時給の違いを比べるなら、どの部署どうしを比べるのが公平だろうか。

8. 三崎実業の課題に図で取り組む

前回の配布資料の図1〜図3を自分で描き、社長の「全員完全出社」の方針が会社の利益にどう影響するかを考える材料にする。まず、配布資料の「データの見方」にある3つの変数を作る。

図1 生産性と時給（勤務形態別）

geom_smooth(method = "lm") で、勤務形態ごとに近似線（回帰直線）を引く。scale_x_log10() と scale_y_log10() で両方の軸を対数目盛にすると、近似線は「対数をとった時給を、対数をとった生産性に回帰したもの」になる（配布資料と同じ）。

議論のポイント（配布資料より）
  • 生産性が同じ社員どうしを比べると、どちらの勤務形態の時給が低いか（図を縦に見る）
  • 時給が同じ社員どうしを比べると、どちらの勤務形態の生産性が高いか（図を横に見る）

図2 生産性と時給（男女別）

図1に facet_wrap(~ sex) を1行足すだけで、男女に分けた図になる。

議論のポイント男性だけ、女性だけで見ても、図1と同じ差があるか。生産性が同じでも、男性と女性で時給の水準は違うか（男女間の賃金の差は、後の回でデータを使って分析する）。

図3 通勤時間と「時給÷生産性」

議論のポイント（配布資料より）
  • 完全出社の社員では、通勤時間と「時給÷生産性」にどんな関係があるか。ハイブリッド勤務の社員ではどうか
  • 通勤時間が長い人ほど、低い時給でもハイブリッド勤務を受け入れてもよいと考えるのはなぜか。通勤にかかる時間が、社員にとってどれだけの価値を持つかを考えよう

会社が得る利益を比べる

会社が得る利益は、社員1人1時間あたり「生産性−時給」（profit）と考えてよい。勤務形態ごとに、数字と図の両方で比べる。

同じ条件の人どうしで比べる

ハイブリッド勤務を選べるのは4部署だけだった。選べない部署の社員まで含めて比べると、部署の違いが混ざってしまう。4部署だけに絞り（filter()）、部署ごとに分けて比べてみよう。

複数の変数をまとめて描く：pivot_longer()

時給と生産性の分布を、勤務形態別に並べて見たい。2つの列（wage_hourly と productivity_hourly）を、「どの変数か」を表す列（variable）と「値」の列（value）の2列にまとめ直す（縦長のデータにする）と、facet_wrap() で変数ごとに分けて描ける。

課題「7. 応用」のヒートマップのコードを書き換えて、部署×勤務形態ごとの「時給÷生産性」の平均を表すヒートマップを描いてみよう。
答えの例
経営会議への報告を考えよう
  • 社長の方針どおり全員を完全出社にしたら、ハイブリッド勤務の社員はどう行動するだろうか。会社は同じ社員に残ってもらうために、何をする必要があるか
  • そのとき、会社が得る利益（生産性−時給）はどう変わりそうか。特に、通勤時間が長い社員について考えよう
  • 今日描いた図の中から、社長を説得するのに最も役立つ図を1枚選び、その図から何が言えるかを3行で説明してみよう
